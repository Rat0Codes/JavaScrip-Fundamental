Projeto Prático - JavaScript Fundamental

Este projeto reúne exercícios práticos abordando conceitos essenciais da linguagem JavaScript.

 Como Executar

Você pode executar o projeto de duas formas:

1. Via Node.js

No terminal, navegue até a pasta do projeto e execute:

node app.js


2. Via Console do Navegador

Abra o navegador (Chrome, Edge, Firefox, etc.).

Pressione F12 ou clique com o botão direito e selecione Inspecionar.

Vá até a aba Console.

Copie todo o conteúdo do arquivo app.js e cole no console, pressionando Enter.

 Conteúdo Coberto

Bloco 1: Fundamentos e Variáveis

Manipulação de variáveis (let e const).

Tratamento de erro (TypeError) na reatribuição de constantes.

Tipos primitivos e uso de typeof.

Interpolação com Template Literals vs Concatenação.

Bloco 2: Funções

Funções declaradas, expressões de função e Arrow Functions.

Demonstração de Hoisting e Temporal Dead Zone (ReferenceError).

Parâmetros com valor padrão.

Bloco 3: Controle de Fluxo

Condicionais com if/else e switch/case.

Laços de repetição for e while.

Operador resto (%) para verificação de números pares e ímpares.
